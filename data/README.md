# Data Directory

This directory contains scripts and data files for the adversarial segmentation project.

## Contents

- `download_coco.sh`: Script to download and extract MS-COCO sample dataset
- `coco/`: Directory for downloaded .pth files (created automatically)

## Usage

### Automatic Download (Recommended)

Run the shell script to automatically download and extract images:
```bash
bash download_coco.sh
